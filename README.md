# BookSwap｜校園二手書交易平台

> 國立虎尾科技大學資訊工程系｜系統分析與設計課程專題

---

## 專案簡介

BookSwap 是一個專為虎科大學生設計的校園二手書交易平台 Demo，以靜態網頁形式呈現系統的核心功能介面。本專案為系統分析與設計課程的書面報告配套 Demo，展示需求分析結果轉換為實際介面的過程。

---

## 功能展示

| 功能 | 說明 |
|------|------|
|  搜尋與篩選 | 關鍵字搜尋、系所 / 年級 / 書況篩選、價格排序 |
|  書籍詳情 | 查看書況描述、賣家評分、上線狀態 |
|  刊登書籍 | ISBN 模擬自動填寫、書況選擇、建議售價參考 |
|  站內訊息 | 買賣雙方站內溝通，支援模擬回覆 |
|  收藏清單 | 收藏感興趣的書籍（localStorage 儲存） |
|  賣家頁面 | 上架書籍列表與買家評價 |

## 使用方式

### 本地預覽

直接用瀏覽器開啟 `index.html` 即可。

### GitHub Pages 部署

1. 將整個 `bookswap/` 資料夾內容推上 GitHub repo 根目錄
2. 進入 repo 設定 → Pages → Branch 選 `main`，目錄選 `/root`
3. 儲存後等待幾分鐘即可透過公開網址瀏覽

---

## 技術說明

- 純靜態網頁，無需後端或資料庫
- 使用 Vanilla HTML / CSS / JavaScript 實作
- 資料為假資料，僅供展示用途
- 收藏功能使用 `localStorage` 儲存狀態
